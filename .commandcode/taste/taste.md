- For large/architectural changes, wants thorough upfront analysis of the existing codebase and the full refactor/blast radius before any code is written ("coba lu pahamin dulu, deep analysis, make no mistakes"), but then wants everything implemented directly rather than turned into a formal plan document or reviewed phase by phase ("oke eksekusi aja langsung semua"). Confidence: 0.7

## Communication
